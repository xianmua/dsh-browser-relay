dsh-browser-relay

DSH 与浏览器之间的通信桥。浏览器扩展面板提交的每个任务，都经本地 relay 在 DSH 里创建真实会话（dsh web UI 会话列表可见、可追问），由 DSH agent 接管执行；页面操作通过 browser_* 工具桥接回浏览器执行。模型与网关沿用 DSH 自身配置，relay 不碰 LLM。

界面预览

工作原理

浏览器扩展 / 悬浮窗任意网页提交任务、展示执行过程
→
本地 relay鉴权、智能等级拦截、任务下发
→
DSH 会话真实会话执行，模型沿用 DSH 配置
→
browser_* 工具命令经长轮询回浏览器，PageController 执行

口令随扩展 zip 自动写入（零配置）；渲染与 DSH web UI 同源（markdown / 代码高亮 / 表格 / 公式 / GenUI 图表）。

五档智能等级

档位在执行层硬拦截，越权工具调用直接拒绝；L4 才有模拟光标与点击特效，其余档位静默执行、人机可同时操作页面。

档位名称行为边界
L1仅问答不触碰页面，纯问答；适合知识类问题，响应最快
L2当前页面只读只读查看页面内容，禁止任何修改；适合「这个页面讲了什么」
L3页面操作 · 静默开放页面操作工具，静默执行（默认推荐）
L4AI 操作演示在 L3 基础上叠加模拟光标与点击特效，直观看到 AI 在做什么
L5DSH 全量放开开放 DSH 其他插件工具，能力上限最高

三步安装

  1. 安装 relay 插件
    前提：本机已安装并登录 DSH。dsh plugin --profile web add git+<插件仓库地址>
  2. 启动 DSH
    dsh web —— relay 随之启动，并自动生成本机口令。
  3. 浏览器装载扩展
    打开向导页 http://127.0.0.1:9916/ 下载扩展 zip 并解压 → edge://extensions 开「开发人员模式」→「加载解压缩的扩展」→ 点工具栏「页面 AI 助手」图标即用。

无需 git / 无需 node / 不碰源码；口令与端点在下载时自动写入 zip，加载即用。

接入自家业务系统（免装扩展）

业务页面 header 加一行 script 即可挂载同款悬浮窗，用户零配置：

<script src="http://127.0.0.1:9916/dsh-assistant.min.js"
        data-token="向导页复制的口令"
        data-workspace="D:\工作区"
        data-ai-level="L3"></script>

支持经后端代理接入、data-* 属性注入默认档位与工作区、DshAssistant.mountPanel() 手动挂载；面板脚本由 relay 托管，relay 更新后刷新页面即拿到新版。

特性

真实 DSH 会话每个任务在 ~/.dsh/sessions 创建真实会话，dsh web UI 可见、可追问，非一次性 mock。
渲染同源复刻markdown / 代码高亮 / 表格 / KaTeX 公式 / GenUI 图表，与 DSH 官方界面同一套渲染核心。
执行层硬拦截智能等级在工具调用层强制生效，越权操作直接拒绝，提示词只是第一道防线。
零配置鉴权本机口令自动生成，随扩展 zip 写入；防本机其他网页冒用，支持连接局域网远程 relay。
面板双形态扩展悬浮窗与业务页面悬浮窗共用同一份源码，最小化收成顶部标签，任务后台照常执行。
零第三方依赖cordis 插件单进程单端口部署，安装即用，不污染 DSH 环境。
